# 기획확정 — 지도 홈 개편 (디폴트 개인 모드 + 상단 셀 4종)

> [!tldr]
> 전체/개인 모드 토글 폐지 — 전체 모드는 Phase 2 유예가 아니라 기획에서 완전 삭제 (MSG-189 근거 소멸).
> 지도 홈 디폴트는 개인 모드(내 업로드 격자), 상단 셀(칩) 4종 — 핫구역·지역 축제·팝업 스토어·코스 추천 — 네이버 지도 상단 칩 디자인 참고.
> 칩은 단일 선택 토글: 한 번에 하나만 활성, 재탭 시 해제 → 개인 모드 복귀. 셀 UI 구현은 MSG-248.

## 이 노트로 답할 수 있는 질문
- 전체 모드(전체 도감)는 어떻게 됐나?
- 지도 홈의 기본 화면과 진입 구조는?
- 상단 셀(칩)은 몇 종이고 어떻게 동작하나?
- 핫구역·축제·팝업·코스는 각각 어디서 데이터를 받나?
- 이 개편으로 무효가 된 기존 문서·티켓은?

## 맥락
2026-07-24 MVP 범위 확대(핫구역 포함)에 이어 미션·이벤트(축제·팝업·코스)까지 지도 홈에 올라오면서, 기존 "전체/개인 모드 셀 전환" 구조(IA 탐색 모드 토글: 나·친구·전체·핫)가 새 기획과 맞지 않게 됨. 2026-07-25 확정.

## 결정
1. **전체 모드 완전 폐지** — 토글 제거, 기획에서 삭제 (유예 아님).
2. **디폴트 = 개인 모드** — 진입 시 내 업로드 격자(개인 도감) 표시.
3. **상단 셀(칩) 4종** — 핫구역 · 지역 축제 · 팝업 스토어 · 코스 추천. 네이버 지도 상단 칩 디자인 참고.
4. **단일 선택 토글** — 하나만 활성, 활성 칩 재탭 시 해제 → 개인 모드 복귀.

## 셀별 데이터 소스 · 티켓
| 셀 | 소스 | 티켓 |
|---|---|---|
| 핫구역 | Redis ZSET(`ZINCRBY hotzone:{시간버킷}`) polling — [[ADR viewport polling SLO]] §6 | MSG-233 · MSG-184 · MSG-92 |
| 지역 축제 | 전국문화축제표준데이터 시드 + 월 갱신 | MSG-224 · MSG-226 |
| 팝업 스토어 | 팝가 크롤 스냅샷 + 주기 갱신 | MSG-235 · MSG-228 |
| 코스 추천 | 두루누비 GPX → 경로·포토스팟 | MSG-225 · MSG-227 |

셀 UI 구현: MSG-248 (신규) · 미션 스토리: MSG-220 · 디자인 시안: MSG-232

## 영향
- PRD ①지도 홈·③핫구역 뷰 → 상단 셀 진입으로 정정 (PRD v4 반영됨)
- IA v2 "탐색 모드 토글" 갈래 폐지 (MSG-138 IA 수정과 연동)
- MSG-189(전체 축 뷰포트 API) 근거 소멸 — 폐지 후보 코멘트 완료
- MSG-187(친구 도감) Phase 2 유지, 진입 방식 재설계 필요
